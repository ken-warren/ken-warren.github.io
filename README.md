# ken-warren.github.io

Portfolio of Kennedy Kyalo, statistician and data analyst.

Static site: `index.html`, `assets/css/styles.css`, `assets/js/main.js`. No build step; push to GitHub Pages.

- Hero: a live scatter plot with a real cubic least-squares fit and 95% band that refits as the data drifts; hover for a crosshair readout.
- Light/dark theme (remembers choice, follows system by default), custom cursor, magnetic buttons, project filters, certificate viewer.
- Respects `prefers-reduced-motion`.
- Contact form uses EmailJS (service/template/public key in `main.js`).
